# 상세 화면 정보 확장 계획

- 작성일: 2026-10-09
- 기준 커밋: `c2723a7` (`main`)
- 규칙: [`docs/conventions/`](conventions/README.md). 지금 코드는 이미 컨벤션과 같은 상태다([개선 기록](improvement-plan.md)).

지금 상세 화면은 이미지·이름·타입·키·몸무게만 보여준다. PokeAPI 가 주는 정보를 더 써서 화면을 채운다.

## 정한 것

| 주제 | 결정 |
|---|---|
| 넣을 정보 | 종족값·특성, 한국어 이름·분류·도감 설명, 진화 체인, 타입 상성 |
| 작업 단위 | 기능 하나마다 데이터와 화면을 한 PR 로 묶는다. PR 마다 화면에 보이는 변화가 있다 |
| 목록 화면 | 이번에는 손대지 않는다. 검색·필터·즐겨찾기는 나중에 다시 정한다 |
| 한국어 표기 | 상세 화면만. 목록은 영문 이름을 유지한다 (목록에서 한국어를 쓰려면 아이템마다 species 호출이 필요하다) |

## 쓸 데이터

| 출처 | 내용 | 추가 호출 |
|---|---|---|
| `/pokemon/{id}` (이미 받는 중) | 종족값 6개, 특성(숨겨진 특성 구분), 기초 경험치 | 없음 |
| `/pokemon-species/{id}` | 한국어 이름·분류·도감 설명, 포획률, 서식지 | 상세 1회 |
| `/evolution-chain/{id}` | 진화 단계와 조건 | 상세 1회 (species 응답의 URL) |
| `/type/{name}` | 타입 상성(2배·0.5배·무효), 한국어 타입 이름 | 타입당 1회, 로컬 캐시 |

## 공통 규칙

- 오프라인 우선을 유지한다. 새 정보도 Room 에 저장하고 화면은 로컬에서 읽는다. ([data.md 1](conventions/data.md#1-구조-필수))
- 네트워크 모델은 `:core:network`, 엔티티는 `:core:database`, 변환은 `:core:data` 에 둔다. 밖에는 `:core:model` 타입만 노출한다.
- 스키마를 바꿀 때마다 버전을 올리고 마이그레이션과 **마이그레이션 테스트**를 추가한다. 캐시만 있는 동안에는 `fallbackToDestructiveMigration` 도 가능하지만, 지우고 다시 받는 대신 `AutoMigration` 을 쓴다. ([data.md 3-2](conventions/data.md#3-2-스키마와-마이그레이션-필수))
- 새 화면 요소는 상태 없는 Screen 에 UI 테스트를, 공용 컴포넌트에는 스크린샷 테스트를 추가한다.
- 갱신 실패는 지금처럼 캐시를 유지한 채 메시지만 띄운다.

## F-1. 종족값과 특성

이미 받고 있는 응답을 쓰므로 네트워크 호출이 늘지 않는다. 가장 먼저 한다.

- **데이터**: `NetworkPokemonDetail` 에 `stats`, `abilities` 추가. `PokemonDetailEntity` 에 종족값 6개 컬럼과 특성 목록 컬럼 추가(스키마 v2, `AutoMigration`).
- **모델**: `PokemonDetail` 에 `stats: PokemonStats`, `abilities: List<PokemonAbility>` (숨겨진 특성 여부 포함).
- **화면**: 종족값 막대 차트와 특성 칩. 막대는 `:core:ui` 의 공용 컴포넌트(`StatBar`)로 만들고 스크린샷 테스트를 붙인다. 막대 색은 타입 색이 아니라 수치 구간으로 정하고 대비 4.5:1 을 지킨다.
- **테스트**: 매퍼(응답 → 엔티티), DAO 마이그레이션, Screen UI(값 표시), 스크린샷.

## F-2. 한국어 이름·분류·도감 설명

- **데이터**: `/pokemon-species/{id}` 호출을 `PokemonNetworkDataSource` 에 추가. `NetworkPokemonSpecies` 는 `names`, `genera`, `flavor_text_entries` 에서 `language.name == "ko"` 만 쓴다. 한국어가 없으면 영어로 떨어뜨린다.
- 도감 설명에는 줄바꿈(`\n`)과 폼피드가 섞여 있다. 저장할 때 공백으로 정리한다. 버전별로 8개쯤 오는데 가장 최근 것 하나만 저장한다.
- **엔티티**: `PokemonDetailEntity` 에 `korean_name`, `genus`, `flavor_text` 추가(스키마 v3).
- **Repository**: `refreshPokemonDetail` 이 상세와 종 정보를 함께 받아 한 트랜잭션으로 저장한다. 두 호출 중 하나만 실패하면 전체 실패로 본다.
- **화면**: 히어로 영역을 다시 만든다. 대표색 배경 + 이미지 + 한국어 이름(큰 글씨)·영문 이름(작은 글씨)·도감 번호·분류, 그 아래 도감 설명.
- **테스트**: 한국어 항목 선택과 폴백, 설명 정리, 두 호출 중 하나가 실패할 때.

## F-3. 진화 체인

- **데이터**: species 응답의 `evolution_chain.url` 에서 ID 를 뽑아 `/evolution-chain/{id}` 를 받는다. 체인을 평탄화해 `(순서, 포켓몬 ID, 영문 이름, 진화 조건)` 목록으로 만든다.
- **엔티티**: `evolution_chain_members` 테이블을 새로 만든다(스키마 v4). 체인 ID 로 묶고, `PokemonDetailEntity` 는 체인 ID 를 들고 있는다.
- 구성원 이름은 로컬에 저장된 한국어 이름이 있으면 쓰고, 없으면 영문을 쓴다. 구성원마다 species 를 더 받지는 않는다.
- **화면**: 가로로 배치한 진화 단계. 각 항목은 이미지와 이름, 사이에 조건(예: `Lv. 16`). 탭하면 그 포켓몬 상세로 이동한다.
- **이동**: 같은 화면으로 다시 들어가는 것이라 `navigateToPokemonDetail(pokeId)` 를 그대로 쓴다. back stack 에 쌓이고 뒤로가기로 돌아온다. 적응형 레이아웃에서도 상세 pane 이 바뀌는지 확인한다.
- **테스트**: 체인 평탄화(분기 없는 3단계, 분기 있는 이브이류), 탭 시 콜백 인자, 내비게이션 계측 테스트에 경로 추가.

## F-4. 타입 상성

- **데이터**: `/type/{name}` 을 받아 `types` 테이블에 한국어 이름과 상성(2배·0.5배·0배 타입 목록)을 캐시한다(스키마 v5). 타입은 20여 개뿐이라 한 번 받으면 재사용한다.
- **계산**: 두 타입이면 배율을 곱한다(예: 불꽃/비행은 바위에 4배). 계산은 데이터 레이어가 아니라 `:core:domain` 의 UseCase 에 둘지, Repository 에 둘지는 F-4 에서 정한다. 여러 화면이 쓰게 되면 UseCase 로 뺀다. ([data.md 6-1](conventions/data.md#6-1-필요할-때만-만든다-필수))
- **화면**: "약점"과 "저항" 섹션. 타입 칩에 배율(×2, ×4, ×0.5)을 함께 보여준다.
- **덤**: 타입 칩의 글자를 한국어로 바꾼다(지금은 `Grass`, 바꾸면 `풀`).
- **테스트**: 단일 타입·이중 타입 배율 계산, 무효 타입, 화면 표시.

## 순서와 이유

```
F-1 종족값·특성      네트워크 호출이 늘지 않고 화면 변화가 크다. 히어로 영역 뼈대도 여기서 잡는다
F-2 한국어 표기      체감이 가장 크다. species 호출이 F-3 의 전제이기도 하다
F-3 진화 체인        F-2 의 species 응답에서 체인 URL 을 얻는다
F-4 타입 상성        독립적이라 마지막에 해도 된다
```

## 확인 방법 (PR 마다)

- `./gradlew clean spotlessCheck lintRelease testDebugUnitTest assembleDebug assembleRelease validateDebugScreenshotTest`
- 계측 테스트는 에뮬레이터를 한 번 띄워 몰아서 돌린다
- 실제 실행으로 화면 확인, 비행기 모드로 캐시 동작 확인
- CI 두 job 통과

## 하지 않는 것

- 목록 화면 검색·필터·즐겨찾기. 즐겨찾기는 사용자 데이터라 마이그레이션 규칙이 더 엄격해진다. 상세 화면을 끝낸 뒤 다시 정한다.
- 기술(move) 목록. 포켓몬당 수백 개라 별도 화면과 페이징이 필요하다.
- 울음소리·애니메이션 스프라이트.
